# Contributing to DSH Plugins

Thank you for helping keep this bilingual plugin directory useful and current.

## Inclusion criteria

A submitted project should:

- be public and materially related to DeepSeek Harness;
- explain its purpose and installation or usage in its README;
- identify its license or usage terms;
- fit one primary directory category;
- avoid deceptive, malicious, or unrelated behavior.

Inclusion improves discoverability. It is not a compatibility certification, security review, or endorsement.

## Submit or correct an entry

- **New plugin:** use the [Submit a plugin](https://github.com/HackSing/dsh-plugins/issues/new?template=submit-plugin.yml) form.
- **Metadata correction:** use the [Update plugin information](https://github.com/HackSing/dsh-plugins/issues/new?template=update-plugin.yml) form.
- **Unavailable repository:** use the [Report a broken link](https://github.com/HackSing/dsh-plugins/issues/new?template=report-broken-link.yml) form.
- **Recommendation or showcase:** use [GitHub Discussions](https://github.com/HackSing/dsh-plugins/discussions).

Plugin additions are not accepted through pull requests. Maintainers may adjust wording or category placement to keep the English and Chinese directories consistent.
